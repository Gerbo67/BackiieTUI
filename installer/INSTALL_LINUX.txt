=========================================================
 GUIA DE INSTALACION DE BACKIIE TUI PARA SERVIDORES LINUX
=========================================================

BackiieTUI esta disenado para correr como un demonio (servicio de fondo)
en servidores Linux (Debian, Ubuntu, CentOS, etc.) y gestionar tus respaldos 
automaticamente a traves de cronjobs internos.

Tambien incluye una Interfaz Visual (TUI) que puedes invocar en cualquier
momento desde la terminal para revisar el estatus o configurar nuevas bases.

---------------------------------------------------------
 1. REQUISITOS PREVIOS
---------------------------------------------------------
- Golang (Go) instalado en el servidor (para poder compilar el proyecto).
- Permisos de Root (sudo) para registrar el servicio en Systemd.

---------------------------------------------------------
 2. INSTALACION
---------------------------------------------------------
1. Clona el repositorio o copia los archivos a tu servidor Linux.
2. Entra a la carpeta de instalacion:
   cd /ruta/a/BackiieTUI/installer

3. Dale permisos de ejecucion al instalador:
   chmod +x install.sh

4. Ejecuta el instalador como administrador:
   sudo ./install.sh

El script hara lo siguiente:
- Compilara el codigo fuente.
- Creara el comando universal "backiie".
- Creara y arrancara el servicio "backiie.service" en Systemd.

---------------------------------------------------------
 3. COMO USARLO
---------------------------------------------------------
Una vez instalado, el demonio ya estara trabajando en segundo plano.

Para abrir la interfaz visual y administrar tus respaldos, simplemente
escribe en cualquier terminal:

   sudo backiie

(Al salir de la interfaz presionando Ctrl+C, el demonio volvera a 
reanudar su trabajo en segundo plano automaticamente).

UBICACION DE ARCHIVOS IMPORTANTES:
- Base de datos local: /var/lib/backiie/backiie.db
- Archivo de Logs:     /var/log/backiie.log

---------------------------------------------------------
 4. COMO VER EL ESTATUS DEL SERVICIO
---------------------------------------------------------
Si necesitas revisar que el demonio este corriendo bien en Linux:

   sudo systemctl status backiie
   sudo journalctl -u backiie -f    (Para ver los logs en tiempo real)

---------------------------------------------------------
 5. DESINSTALACION COMPLETA
---------------------------------------------------------
Si necesitas remover BackiieTUI por completo del servidor, borrando 
servicios, binarios, base de datos local y logs:

1. Ve a la carpeta de instalacion del proyecto original:
   cd /ruta/a/BackiieTUI/installer
2. Dale permisos al desinstalador:
   chmod +x uninstall.sh
3. Ejecutalo:
   sudo ./uninstall.sh

El servidor quedara limpio sin dejar rastros.
